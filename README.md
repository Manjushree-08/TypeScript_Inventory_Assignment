# TypeScript Inventory Assignment

This repository contains TypeScript practical exercises and a product inventory management website developed as part of the Advanced Web Technologies assignment.

## Part A: TypeScript Practicals

- Variables and data types
- Functions and default parameters
- Array operations using `map()`
- Interfaces and interface inheritance
- Type checking and debugging errors
- TypeScript compiler configuration

## Part B: Moss & Metric Inventory Manager

A responsive product inventory website built using HTML, CSS, and TypeScript.

### Features

- Display product inventory and summary statistics
- Search products by name or category
- Filter products by stock status
- Add new products
- Remove products
- Calculate total inventory value
- Identify products with low stock
- Responsive user interface

### Technologies Used

- TypeScript
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## How to Run

1. Install Node.js and TypeScript.
2. Open the relevant project folder in the terminal.
3. Run `tsc` to compile the TypeScript files.
4. Open `PartB_Inventory_Manager/index.html` in a web browser to view the inventory website.

## Project Structure

- `PartA_TypeScript_Practicals/` — TypeScript exercises and debugging.
- `PartB_Inventory_Manager/` — Inventory manager website.
- `README.md` — Project documentation.
